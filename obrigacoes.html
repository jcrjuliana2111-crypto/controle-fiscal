Como o processo funciona

  1. Cadastro: cada empresa aqui no painel tem o código do Domínio, o CNPJ e as obrigações que entrega.
  2. Gerar competência: cria a lista do mês, com os vencimentos.
  3. Robô (no Windows, onde o Domínio está instalado), por empresa:
    • I · Importação: troca de empresa no Domínio e importa os XMLs da pasta da competência;
    • G · Geração: gera o arquivo de cada obrigação (SPED Fiscal, EFD Contribuições...);
    • C · Conferência: valida o arquivo (estrutura, CNPJ, período, apuração, cruzamento com os XMLs). Com erro, fica divergente e não segue para a entrega;
    • E · Entrega: reconhece o recibo do ReceitaNet/PVA na pasta de recibos e marca como transmitido. Ele só transmite sozinho se você liberar isso no config.
  4. Obrigações de entrega manual (DCTFWeb, PGDAS-D, ISS...) recebem o recibo aqui no painel, pelo botão ✔.

Instalação (uma vez, na máquina do Domínio)

1. Instale o Python 3.11+ (marque "Add to PATH")
2. Copie a pasta robo-dominio do repositório para a máquina
3. cd robo-dominio
   pip install -r requirements.txt
   copy config.exemplo.yaml config.yaml      (ajuste as pastas e o executável)
   setx DOMINIO_SENHA "sua-senha"            (a senha não fica em arquivo)

Calibrar as telas (uma vez por versão do Domínio)

python -m robo_dominio mapear --janela "Domínio"
python -m robo_dominio receita trocar_empresa --empresa 123 --passo-a-passo
python -m robo_dominio receita importar_xml  --empresa 123 --competencia 2026-09 --passo-a-passo

As receitas ficam em receitas.yaml. Menus e atalhos mudam entre versões do Domínio, então ajuste cada passo até a receita rodar sozinha.

Uso no dia a dia

python -m robo_dominio ciclo --competencia 2026-09                       (todas as empresas)
python -m robo_dominio ciclo --competencia 2026-09 --empresa 123 --empresa 456
python -m robo_dominio ciclo --competencia 2026-09 --etapas conferir,entregar
python -m robo_dominio ciclo --competencia 2026-09 --simular             (só mostra o que faria)
python -m robo_dominio conferir --tipo sped_fiscal --arquivo SPED.txt --cnpj 12345678000199 --competencia 2026-09 --xml D:\XML\123\202609

Para rodar sem ninguém por perto, agende o executar_robo.bat no Agendador de Tarefas do Windows. O usuário precisa estar logado com a tela desbloqueada, porque o RPA usa a tela.
