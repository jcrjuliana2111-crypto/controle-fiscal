API de emissão de NFS-e

API REST em JSON. Endereço base: %APP_URL%/api/v1. Disponível a partir do plano Profissional.

Autenticação

Crie uma chave em Integrações e envie no cabeçalho de todas as chamadas. A chave tem o perfil escolhido na criação (emitir e consultar, só consultar ou tudo).

Authorization: Bearer nfk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Limite: 600 requisições por minuto por conta. Acima disso a resposta é 429.

Emitir nota

POST /notas. Use o cabeçalho Idempotency-Key com um identificador único do seu lado (por exemplo, o número do pedido): se a mesma chave for enviada de novo, devolvemos a nota já criada em vez de emitir outra.

curl -X POST %APP_URL%/api/v1/notas \
  -H "Authorization: Bearer $CHAVE" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: pedido-10457" \
  -d '{
    "prestadorId": "UUID da empresa emitente",
    "competencia": "2026-10-01",
    "referenciaExterna": "pedido-10457",
    "tomador": {
      "tipo": "PJ",
      "documento": "12.ABC.345/01DE-35",
      "nome": "Cliente Exemplo Ltda",
      "email": "financeiro@cliente.com.br"
    },
    "servico": {
      "itemListaServico": "17.19",
      "codigoTributacaoNacional": "171901",
      "discriminacao": "Honorários contábeis de setembro/2026"
    },
    "valores": { "servico": 1850.00, "aliquotaIss": 2, "issRetido": false }
  }'

A resposta traz a nota com status:

autorizadaEmitida. Tem numero e chaveAcesso (Portal Nacional) ou codigoVerificacao (prefeituras).
rejeitadaO fisco recusou. Veja mensagens; corrija e envie com outra Idempotency-Key.
processandoSem resposta definitiva (fisco fora do ar). Consulte depois, não reenvie.
validadaSó São Paulo em homologação: mensagem validada, nenhuma nota gerada.

Campos de tomador.tipo: PJ, PF, EXT (exterior, informe nif) e NI (não identificado). Em valores também são aceitos deducoes, descontoIncondicionado, descontoCondicionado, pis, cofins, inss, ir, csll, outrasRetencoes e pisCofinsRetido. Para IBS/CBS, envie ibsCbs com cClassTrib, cIndOp, finNFSe e indDest.

Para obter o prestadorId: GET /prestadores.

Consultar e listar

  • GET /notas/{id}: dados da nota.
  • POST /notas/{id}/consultar: atualiza a situação junto ao fisco (use para notas em processando).
  • GET /notas?status=autorizada&de=2026-10-01&ate=2026-10-31&busca=cliente&pagina=1&porPagina=50: lista paginada com itens e total.
  • POST /calcular: calcula ISS, retenções e valor líquido sem emitir.

Cancelar

POST /notas/{id}/cancelar
{ "codigo": 1, "motivo": "Valor do serviço informado incorretamente" }

Códigos: 1 erro na emissão, 2 serviço não prestado, 9 outros. A justificativa precisa de 15 a 255 caracteres.

XML e DANFSe

  • GET /notas/{id}/xml: XML autorizado. ?tipo=envio devolve o XML assinado que enviamos.
  • GET /notas/{id}/danfse: PDF oficial do Portal Nacional ou página para impressão nas prefeituras.

Avisos (webhooks)

Cadastre um endereço em Integrações. Enviamos um POST com JSON quando a nota muda de situação: nota.autorizada, nota.rejeitada, nota.cancelada e nota.processando.

{ "evento": "nota.autorizada", "criadoEm": "2026-10-10T17:32:05Z", "dados": { "id": "…", "status": "autorizada", "numero": "418", … } }

Valide a origem pelo cabeçalho X-Assinatura: t=<unix>,v1=<hex>, um HMAC-SHA256 de "<t>.<corpo>" com o segredo mostrado ao criar o aviso:

// Node.js
const [, t, v1] = req.headers['x-assinatura'].match(/t=(\d+),v1=([0-9a-f]+)/);
const esperado = crypto.createHmac('sha256', SEGREDO).update(`${t}.${corpoBruto}`).digest('hex');
const valido = crypto.timingSafeEqual(Buffer.from(esperado), Buffer.from(v1));

Responda com status 2xx em até 10 segundos. Falhas são reenviadas em 1, 5, 30, 120, 360 e 720 minutos.

Serviços da Receita (Integra Contador)

  • GET /fiscal/catalogo: lista os serviços disponíveis, com campos de cada um.
  • POST /fiscal/executar com { "codigo": "PGMEI.GERARDASPDF21", "contribuinte": "CNPJ", "valores": { "periodoApuracao": "202609" } }. A resposta traz mensagens, dados e documentos (PDFs em GET /fiscal/documentos/{id}).
  • GET /fiscal/das-mei?competencia=AAAAMM e POST /fiscal/das-mei/gerar com { "contribuinteId": "...", "competencia": "AAAAMM" }.

Erros

Erros vêm como { "erro": "mensagem", "erros": [{ "campo": "...", "mensagem": "..." }] }.

401Chave ausente, inválida ou revogada.
402Limite do plano atingido ou teste encerrado.
403O perfil da chave não permite a ação, ou a conta está suspensa.
404Registro não encontrado nesta conta.
409Conflito (por exemplo, número de RPS já usado).
422Dados inválidos; veja erros.
429Muitas requisições; aguarde e tente de novo.
